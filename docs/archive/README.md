# Archives documentaires

Les archives sont conservées comme contexte historique et ne définissent pas les exigences actuelles de Core.

## Projet Alumni ITMA

Le dossier [`alumni-itma/`](alumni-itma/) regroupe huit documents importés d'un autre dépôt : vue d'ensemble, contrats Django/API, brief frontend, modèle de données, proposition d'architecture et audits UX. Aucun backend Django, frontend Vite ou domaine Alumni correspondant n'existe dans Core.

Ces fichiers ont été archivés plutôt que supprimés afin de préserver leur contenu. Avant de réutiliser une information d'archive, vérifier qu'elle concerne bien le projet visé et la comparer à son code actuel.
